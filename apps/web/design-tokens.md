# Дизайн-токены AutoBring

Кратко: почему выбраны именно эти токены, чтобы не откатиться на дефолтный
shadcn/«ИИ-стартап» вид при добавлении новых экранов.

## Палитра

- **paper-*** — почти белые поверхности marketplace (Clutch / Cars & Bids), не
  кремовый «editorial» фон и не slate по умолчанию.
- **ink-*** — нейтральный тёмный текст без холодного синеватого slate.
- **rust-500** как единственный основной акцент — ржаво-медный CTA. Осознанно
  НЕ фиолетовый/индиго (дефолтный «AI product» градиент).
- **harbor-*** — вторичный акцент для статусов/таймлайна сделки.

## Типографика

- Бренд: **Fraunces** (только wordmark / редкие акценты).
- UI и заголовки секций: **Public Sans** — лёгкий гротеск marketplace, не Inter.

## Форма

- Скругления умеренные (0.5–1rem). Карточки — только там, где есть
  взаимодействие (лоты каталога). Hero без карточек: full-bleed фото + светлый
  градиент под текст.

## Правило для новых экранов

Перед добавлением нового экрана — сверяться с этим файлом. Ориентир по плотности
и «воздуху» — современные витрины вроде Clutch / Cars & Bids, а не тяжёлый
тёмный editorial hero.
