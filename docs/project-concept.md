# Концепция веб-приложения: платформа подбора и заказа авто из Японии, Кореи и Китая

> Рабочее название: **AutoBridge** (варианты: JDM Route, Ввоз.про — выбрать позже)

## 1. Контекст и обоснование

Изучено 8 действующих игроков рынка: jptrade.ru, carwin.ru, japantransit.ru, akira-auto.ru,
tokidoki.su, sferacar.ru, jplife.ru, worldcar.ru. Все они — B2C-сайты компаний-перегонщиков
(«под ключ»: подбор → покупка на аукционе → доставка → растаможка → постановка на учёт).
Ниже — то, что реально увидено на живых страницах jptrade.ru, carwin.ru и tokidoki.su
(остальные используют тот же паттерн с вариациями).

### 1.1. Что у конкурентов сильное (забрать себе)

### 1.2. Слабые места конкурентов (наши точки роста)

| Проблема | Где заметно | Как решаем в AutoBridge |
|---|---|---|
| Устаревший, «текстовый» UX 2012–2016 годов: тяжёлые мега-меню, десятки вложенных ссылок, нет ощущения продукта | почти все | Современный React SPA/ISR-фронт, чистая навигация, фасетный поиск вместо древовидных меню |
| Калькулятор — отдельная статичная страница, не связан с конкретным лотом в реальном времени | carwin, jptrade | Калькулятор — виджет на карточке авто, пересчитывается на лету при смене курса/объёма/года |
| Нет личного кабинета — статус сделки узнаётся по телефону/мессенджеру у менеджера | все сайты | Личный кабинет с таймлайном сделки (аукцион → выкуп → порт → таможня → выдача), пуши/email |
| Заявка = «оставьте телефон, вам перезвонят» — нет самообслуживания | все сайты | Возможность самостоятельно фильтровать, сохранять избранное, делать ставки-запросы и сравнивать без звонка |
| Сравнение моделей практически отсутствует как функция (только карточки по отдельности) | все сайты | Полноценный компаратор 2–4 авто (характеристики, итоговая цена под ключ, оценка аукциона) |
| Слабая персонализация: одна и та же лента для всех | все сайты | Подбор по бюджету/семье/задачам с сохранением фильтров, алерты по появлению лота под критерии |
| Мобильная версия — обрезанная десктопная (тяжёлые меню, медленная загрузка фото) | все сайты | Mobile-first, ленивая загрузка изображений, скелетоны, PWA-подход |
| Нет прозрачной истории лота/цены на самом сайте (только «уникальный сервис проверки» по запросу) | carwin упоминает как платную фичу | Показываем историю торгов лота (если аукционный лист участвовал в прошлых торгах) прямо в карточке |
| Разрозненные калькуляторы под Японию/Корею/Китай, разный UX на разных субдоменах (jpkorea.ru у jptrade) | jptrade | Единый расчётный движок и единый UI для всех трёх стран с самого начала |
| Юридические тексты и договоры — просто PDF-ссылки, без интерактивного сопровождения сделки | все сайты | Интерактивный чек-лист документов + статус на каждом этапе, e-signature интеграция (roadmap) |

## 2. Целевая аудитория

1. **Частный покупатель («самостоятельный»)** — 25–45 лет, готов разобраться сам, хочет
   прозрачность цены и контроль на каждом шаге, не любит «продавливающих» менеджеров.
2. **Покупатель «под ключ»** — доверяет компании полностью, хочет минимум решений,
   важны отзывы, гарантии, договор.
3. **Автоподборщик/перекупщик (B2B-лёгкий)** — покупает регулярно несколько машин,
   нужен быстрый доступ к статистике аукционов и массовый просмотр лотов, экспорт в Excel.
4. **«Присматривающийся»** — ещё не решил, из какой страны и какой бюджет; нужен
   контент, калькулятор «что почём», сравнение стран ввоза.

Все — русскоязычная аудитория (Россия + частично СНГ/Абхазия/Грузия по логистике).

## 3. Ценностное предложение

> «Один расчёт, одна панель, три страны: подбирайте, сравнивайте и отслеживайте свой автомобиль
> из Японии, Кореи или Китая от лота на аукционе до постановки на учёт — без звонков ради каждой цифры.»

Дифференциаторы:
- **Единый живой калькулятор** «под ключ» для JP/KR/CN, встроенный в карточку каждого лота.
- **Личный кабинет со статусом сделки** — как трек-номер посылки, только для автомобиля.
- **Компаратор** и **алерты по фильтрам** («сообщить, когда появится Honda Fit 2018–2020, ≤700 тыс₽»).
- **Прозрачная история лота** прямо на странице, без «закажите проверку».
- Быстрый, современный, честный по скорости и мобильный интерфейс.

## 4. Функциональный состав (по фазам)

### Фаза 1 — MVP (учебный трек, Япония)
- Каталог/статистика лотов Японии с фильтрами (марка, модель, год, объём, оценка, цена)
- Карточка автомобиля: фото, характеристики, аукционный лист (перевод), встроенный калькулятор стоимости под ключ
- Калькулятор растаможки как отдельный инструмент (для тех, кто ещё не выбрал авто)
- Форма заявки/расчёта с множественным выбором канала связи
- Избранное (локально/в аккаунте)
- Блог/статьи (SEO, доверие)
- Адаптивная свёрстка, тёмная/светлая тема

### Фаза 2 — Личный кабинет и live-функции
- Регистрация/авторизация (email, соцсети/Telegram Login)
- Личный кабинет: мои заявки, избранное, сохранённые фильтры, алерты
- Таймлайн сделки со статусами (аукцион → выкуп → порт отправления → таможня РФ → выдача)
- Live-аукционы (обновление лотов через WebSocket/SSE), «watchlist» лота
- Компаратор автомобилей (2–4 карточки бок о бок)
- Уведомления (push/email/Telegram-бот)

### Фаза 3 — Мультистрана и масштабирование
- Полноценные разделы Корея и Китай с тем же движком калькулятора и таймлайна
- Мультивалютность и авто-обновление курсов (¥/₩/¥CNY → ₽)
- B2B-режим: массовый просмотр, экспорт таблиц, API-доступ для партнёров-подборщиков
- Админ-панель для контент-менеджеров и менеджеров сделок
- i18n-каркас (на случай расширения на другие СНГ-рынки)
- PWA/офлайн-режим для избранного и статусов заявки

## 5. Информационная архитектура (основные экраны)

1. Главная — выбор страны ввоза, топ-модели, калькулятор-тизер, соц. доказательства
2. Каталог/поиск (фасетные фильтры, URL ⇄ состояние синхронизированы)
3. Карточка автомобиля (галерея, характеристики, калькулятор, «добавить в сравнение», CTA заявки)
4. Калькулятор растаможки (standalone-инструмент + встроенный в карточку вариант)
5. Компаратор (до 4 авто)
6. Личный кабинет (заявки / избранное / алерты / таймлайн сделки)
7. Блог/статьи
8. О компании / договор / контакты (доверие)
9. Админ-панель (для фазы 3)

## 6. Черновая модель данных

```
Car
  id, source_country (JP|KR|CN), make, model, year, mileage_km,
  engine_cc, transmission, drive_type, auction_grade, auction_date,
  base_price_source_currency, currency, photos[], auction_sheet_url

PriceCalculation
  car_id (nullable — можно считать «с нуля»), fx_rate_snapshot,
  customs_duty, util_fee, logistics_cost, service_fee, total_rub

Deal (сделка)
  id, user_id, car_id, status (draft|bidding|purchased|shipped|
  customs|ready|delivered), status_history[], documents[]

User
  id, name, contacts (phone/telegram/whatsapp), role (buyer|manager|admin)

Favorite, Alert (filters_json, notify_channel), ComparisonSet
```

## 7. Технологический стек (ориентир под курс)

- **Frontend:** React 19 + TypeScript, Vite; Next.js как опция для SSR/SEO страниц каталога и блога
- **Состояние сервера:** TanStack Query (кэш, инвалидция, фоновые обновления для live-аукционов)
- **Локальное/UI-состояние:** Zustand (либо Context+useReducer для учебных целей)
- **Формы и валидация:** React Hook Form + Zod (заявка, калькулятор, фильтры)
- **Стили:** Tailwind CSS + компонентная библиотека (shadcn/ui) для скорости
- **Real-time:** WebSocket/SSE для ленты аукциона и статусов сделки
- **Виртуализация списков:** TanStack Virtual для каталога из тысяч лотов
- **Тестирование:** Vitest + React Testing Library, Playwright для e2e
- **Бэкенд (для полноты продукта, вне ядра курса):** Node/NestJS или Fastify + Postgres,
  либо мок-API (MSW) на время обучения, чтобы фокус оставался на React

## 8. Монетизация (для полноты концепции)

- Комиссия за подбор/сопровождение сделки (как у конкурентов)
- Платные алерты/приоритетный доступ к «горячим» лотам (freemium)
- B2B-подписка для автоподборщиков (API/массовая выгрузка)
- Партнёрские интеграции: страхование, логистика, кредитование

## 9. Метрики успеха продукта

- Время от захода на сайт до отправленной заявки/расчёта
- % пользователей, вернувшихся в личный кабинет проверить статус (retention)
- Конверсия «просмотр каталога → заявка» в сравнении с конкурентами
- Точность калькулятора (расхождение с итоговым счётом)

## 10. Риски и особенности рынка

- Курсы валют и пошлины меняются регулярно — движок расчёта должен быть легко обновляемым (не хардкод)
- Часть исходных данных (аукционные листы) — на японском/корейском/китайском, нужен слой перевода
- Антибот-защита у реальных аукционных площадок — в учебном проекте используем моковые/открытые данные, не парсим боевые аукционы
- Юридическая чувствительность (растаможка, договоры) — в приложении это UX-слой поверх реального сервиса, не юридическая консультация
